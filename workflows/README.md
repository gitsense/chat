# Guided workflows

Guided workflows let an agent walk a person through a process, present choices,
make authorized changes as decisions are made, and leave behind a working
system. Each workflow separates the lead instructions, delegated agent roles,
and prompts used to pair other tools or agents.

Available for testing:

- [Pair agents across tools](agent-collaboration/README.md) brings Pi sessions and
  supported coding agents into one Group. Paired agents use visible Buddies,
  and an Observer can be added when requested.
