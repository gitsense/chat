# Guided workflows

Guided workflows let an agent walk a person through a process, present choices,
make authorized changes as decisions are made, and leave behind a working
system. Each workflow separates the lead instructions, delegated agent roles,
and prompts used to connect other tools or agents.

Available for testing:

- [Connect your agents with Buddies](agent-observer/README.md) builds a Group
  where external coding agents publish updates through visible Buddies, with an
  optional Observer added when requested.
